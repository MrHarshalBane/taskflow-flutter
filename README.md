# TaskFlow 🚀

A modern Flutter task management application built using Flutter and Dart.

## ✨ Features

- Add, edit and delete tasks
- Mark tasks as completed
- Search tasks
- Filter by status
- Categories and priorities
- Dark Mode
- Local JSON storage
- Responsive Material 3 UI

## 📱 Screens

- Splash Screen
- Home Screen
- Add Task
- Edit Task
- Task Details
- Settings

## 🛠 Tech Stack

- Flutter
- Dart
- JSON
- Material Design

## 📂 Project Structure

```
lib/
├── models/
├── screens/
├── widgets/
├── services/
├── theme/
└── utils/
```

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/taskflow-flutter.git

cd taskflow-flutter

flutter pub get

flutter run
```
